# my-first-ai

このリポジトリは、**AIアシスタントといっしょにGitHub作業を練習するため**の小さな練習場所です。

難しいことはありません。1つずつ試せば大丈夫です。

## ここでできること

- ファイルを作る
- 文章を少し直す
- 変更を保存する（コミット）

## 使い方（はじめての人向け）

1. このリポジトリを開きます。
2. ファイルを1つ作るか、文章を少し変更します。
3. 変更内容を確認します。
4. コミットします。

## コツ

- 最初は小さい変更だけでOKです。
- うまくいかなくても、やり直せます。
- 分からないときは、1つずつ質問しましょう。
